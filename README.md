# Sonoform Labs

Open source research in audio machine learning, music information retrieval, and computational bioacoustics.

## Projects

- **[Speculative Audio Generation Engine](https://github.com/Sonoform-Labs/Speculative-Audio-Generation-Engine)**: pre-generating game sound effects with a lightweight text-to-audio model.
- **[BirdCLEF+ 2026](https://github.com/Sonoform-Labs/BirdClef)**: partial-label evaluation of interpretable prototype components with temporal aggregation for bioacoustic classification.
